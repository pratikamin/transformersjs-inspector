Worker bridge

The pipeline runs inside a module Web Worker (demo/inference.worker.ts) that calls attach(pipe, { bus, panel: false }) and exposeToPage(bus). This page never loads Transformers.js: connectWorker(worker) gives it a bus that mirrors the worker's events, and mountPanel(bus) renders them. Load values in the panel fetches the tensor from the worker.
